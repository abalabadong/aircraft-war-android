# 运行说明

## 环境

- JDK 8 及以上（本机使用 Microsoft OpenJDK 21 验证通过）
- IntelliJ IDEA（工程文件为 `AircraftWar-base.iml`，LANGUAGE_LEVEL = JDK_11）

## 用 IntelliJ IDEA

1. `File → Open`，选择本目录 `AircraftWar-base-源码`（或直接选 `AircraftWar-base.iml`）。
2. 确认 SDK 已配置（Project Structure → SDK）。
3. 运行 `src/edu/hitsz/application/Main.java`。

## 用命令行

在 `AircraftWar-base-源码` 目录下：

```powershell
# 编译
javac -encoding UTF-8 -d out (Get-ChildItem -Recurse src -Filter *.java | ForEach-Object FullName)

# 运行（工作目录保持在项目根目录，图片/音频按相对路径读取）
java -cp out edu.hitsz.application.Main
```

## 资源

- 图片：`src/images/`（背景、英雄机、各型敌机、子弹、道具）
- 音频：`src/videos/`（bgm、boss bgm、爆炸、命中、游戏结束、拾取）
